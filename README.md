A paper-trading bot for the pump.fun replay sprint. It waits for a liquid breakout: a coin with at least 10 SOL of real reserves whose price breaks 50% above the high of its first 30 slots on at least 0.5 SOL of net buy flow, with the creator not selling. It takes one fixed 0.1 SOL stake per coin (split into per-order-cap pieces when the 1%-of-reserve cap binds) and rides it with a wide trailing stop and no tight take-profit, so the few coins that run 5–15x pay for the many that do not. A tiny probe keeps the run above the guardrail minimums when the main signal goes quiet.

## Run it

```sh
node main.ts
```
